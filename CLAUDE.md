# CLAUDE.md

Beacon's guidance for coding agents lives in two files. Read both before changing anything:

- [`AGENTS.md`](AGENTS.md): project overview, important files, working rules, and build and test commands.
- [`CONTRIBUTING.md`](CONTRIBUTING.md): branch names, commit messages, scopes, and pull request titles.

Branches, commits, and pull request titles follow Conventional Commits with a scope, for example `feat(settings): add theme setting with light and dark appearances` on a `feat/theme-settings` branch.
